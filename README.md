# tfg-avatar-virtual

Esta aplicación web tiene como objetivo estudiar la librería MediaPipe de Google y observar sus funcionalidades en el
contexto de la detección de rostros y seguimiento de movimientos faciales.

Se utiliza la librería Media Pipe de Google, capaz de la detección de objetos, de gestos faciales, gestos de manos, segumiento facial, y más funcionalidades relacionadas con el audio y texto.
